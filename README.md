# Live Photo Converter (iOS / SwiftUI)

Приложение для iOS, которое находит в галерее короткие видео заданной длительности (гибкая настройка «От» и «До», быстрые пресеты 1.5–3.0с, 2.0–3.0с, 2.0–5.0с и т.д.), конвертирует их в полноценные **Live Photo** и удаляет исходные видеофайлы, оставляя только интерактивные «живые» фотографии.

---

## ✨ Возможности

- ⏱ **Гибкий выбор длительности «От» и «До»**: регуляторы слайдеров и шаговых кнопок (шаг 0.1 с) для выбора любого интервала, плюс готовые кнопки быстрых пресетов.
- 📸 **Полноценный стандарт Apple Live Photo**: связка JPEG-стоп-кадра (`kCGImagePropertyMakerAppleDictionary`, тег `17`) и QuickTime MOV с метаданными `com.apple.quicktime.content-identifier` и треком `com.apple.quicktime.still-image-time`.
- 🗑 **Безопасное удаление оригиналов**: пакетное удаление всех сконвертированных исходных видео в едином системном диалоге (пользователь подтверждает удаление один раз для всей партии).
- 🚀 **Автоматическая сборка IPA через GitHub Actions**: сборка на облачных macOS-раннерах без необходимости локального Mac.

---

## 📦 Установка готового IPA

После пуша в GitHub репозиторий автоматически запускается GitHub Actions workflow:
1. Перейдите во вкладку **Actions** репозитория на GitHub.
2. Откройте последний запуск **Build iOS IPA**.
3. В разделе **Artifacts** скачайте архив `LivePhotoConverter-IPA` (содержит `LivePhotoConverter.ipa`).
4. Также файл прикрепляется к разделу **Releases**.
5. Установите `.ipa` на iPhone с помощью любой удобной утилиты:
   - **TrollStore** (для устройств с поддержкой)
   - **AltStore** / **SideStore**
   - **Sideloadly**
   - **Scarlet** / **ESign**

## 🛠 Локальная сборка в Xcode

1. Склонируйте репозиторий.
2. Если установлен `xcodegen`:
   ```bash
   brew install xcodegen
   xcodegen generate
   open LivePhotoConverter.xcodeproj
   ```
3. Или создайте новый проект в Xcode и перенесите файлы из папки `Sources/`.
